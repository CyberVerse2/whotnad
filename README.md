# whotnad

Multiplayer Whot on Monad with escrowed matches, s, match settlement, and profile/history flows.

## Getting Started

Run the development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

Core app areas:

- `app/lobby` for matchmaking
- `app/play` for escrow funding and gameplay
- `app/profile/[address]` for match history and claims
- `contracts/` for the Monad tournament pool contract

## Monad Blitz Lagos Submission

This repo also includes the submission context from the original remote setup.

1. Visit the `monad-blitz-lagos` repo and fork it: [monad-developers/monad-blitz-lagos](https://github.com/monad-developers/monad-blitz-lagos)
2. Give the fork your project name and description, and fork the `main` branch.
3. Add your project code, docs, and changes in your fork.
4. Continue the submission flow in [Blitz Portal](https://blitz.devnads.com)
